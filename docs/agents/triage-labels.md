# Rôles de tri

Les skills parlent de cinq rôles de tri. Ce tableau donne la chaîne écrite dans la ligne `Status:` des tickets de `docs/tickets/`.

| Rôle dans mattpocock/skills | Chaîne dans SOLAR | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | À évaluer |
| `needs-info` | `needs-info` | En attente d'une précision de Solaire |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifié, prêt pour un agent |
| `ready-for-human` | `ready-for-human` | Demande une intervention humaine |
| `wontfix` | `wontfix` | Ne sera pas fait |
